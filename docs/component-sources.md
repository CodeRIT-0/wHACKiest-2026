# Component sources and design direction

The supplied Whackiest video is the visual reference: ivory paper, engraved rules, brass mechanical computation, orange valves, electric-blue circuit traces, early CRT computers, and later browser windows. The original ivory editorial sections and dark circuit / tracks sequence are connected by scroll-linked handoffs. The animated hero retains its ivory background and brass, blue, and orange accents.

These are local source adaptations, not remote runtime dependencies:

| Local component                          | Original reference                                                                                                                                                                                                                         | Adaptation                                                                                                                                                                            |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/components/ui/retro-button.tsx`     | [Neobrutalism Button](https://www.neobrutalism.dev/docs/button), [registry source](https://neobrutalism.dev/r/button.json)                                                                                                                 | Physical offset shadow and press motion, ivory/black/orange variants. Native buttons and Next links preserve their correct semantics without installing a second primitive framework. |
| `src/components/ui/transition-panel.tsx` | [Motion Primitives TransitionPanel](https://github.com/ibelick/motion-primitives/blob/main/components/core/transition-panel.tsx), also presented in the [21st Motion Primitives library](https://21st.dev/@ibelick/components/text-effect) | Track panel crossfade with a short vertical transition, wait mode, and a live reduced-motion preference.                                                                              |
| `src/components/ui/text-shimmer.tsx`     | [Prompt Kit TextShimmer](https://github.com/ibelick/prompt-kit/blob/main/components/prompt-kit/text-shimmer.tsx)                                                                                                                           | Reusable native span, CSS gradient, theme colors, reduced-motion fallback. Used in the hero signal, CRT reward display, and section handoffs.                                         |

## Great UI refinements

- [BlurScrollReveal](https://www.great-ui.com/components/blur-scroll-reveal), [source](https://github.com/Saurabh-2607/GreatUI/blob/main/components/ui/BlurScrollReveal.tsx): `src/components/ui/scroll-reveal.tsx` adapts the shared scroll-position / opacity / vertical-offset mapping to whole section headings. It inherits the site typography, keeps text readable, avoids measuring and duplicating lines, and bypasses motion for reduced-motion preferences or server rendering.
- [CurtainPageTransition](https://www.great-ui.com/components/curtain-page-transition), [source](https://github.com/Saurabh-2607/GreatUI/blob/main/components/ui/CurtainPageTransition.tsx): `ThemeTransition.tsx` adapts its two opposed half-panels to a contained section handoff. Their motion follows scroll continuously instead of intercepting route changes or using timers. The bridge colors still meet neighboring backgrounds exactly.
- [Card source](https://github.com/Saurabh-2607/GreatUI/blob/main/components/ui/Card.tsx): `src/components/ui/schematic-card.tsx` adapts the animated divider into an accessible article with a small hover lift and the established paper/circuit visual style. Used by the team preview cards.

Great UI uses its own custom license, rather than the MIT notices above. The complete notice is retained in [licenses/great-ui.txt](licenses/great-ui.txt). These components are integrated into the event website, not distributed as a standalone UI library.

`SmoothScrolling.tsx` uses [Lenis](https://github.com/darkroomengineering/lenis) to ease wheel scrolling at a 0.12 interpolation rate while retaining the native document scroll position. Native touch, keyboard scrolling, and sticky positioning remain intact. Timeline controls share the same scroll engine; reduced motion destroys the easing instance and uses native scrolling. The existing circuit spring still synchronizes the camera, current and card reveal. The Lenis license is included in [licenses/lenis.txt](licenses/lenis.txt).

Typography is now assigned by role: Barlow Condensed 700 for section/display headings; Space Grotesk 600 for card titles; Space Grotesk for body copy and controls; Courier New for short instrument labels. Core sizes and motion timings are defined with the shared variables in `src/app/editorial.css`.

The circuit geometry and continuous scroll source remain custom. Upcoming card bodies are transparent until the current begins its final approach, then gain opacity continuously until the checkpoint. Reversing scroll reverses that reveal. Frames stay visible as circuit destinations. Reduced motion and no JavaScript keep the descriptions fully readable.

The organiser supplied the prize amounts: ₹25,000 / ₹15,000 / ₹10,000. `src/lib/event-content.ts` holds those amounts plus clearly marked mock team names and fictional partner wordmarks. Timeline dates remain planning placeholders. Registration is a demonstration only: it neither sends applications nor stores personal data. The site footer marks the remaining mock content.
